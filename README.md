# Prehnite Pong

Full-colour Python 3 neon pong/volley arcade for ElbowOS.

Left paddle vs right. Neon cyan vs magenta. Gold ball on navy grid.
W / S or arrow keys to move left paddle. Right is AI.
Score rallies as the ball bounces.

## Play
```bash
pip install -r requirements.txt
python3 prehnite_pong.py --play
```

## Record a 9:16 reel
```bash
python3 prehnite_pong.py --record
```
Outputs PREHNITE_PONG_ElbowOS.mp4 (1080x1920, 15s @ 30fps).
